# TODO

**Every open task in this repo lives here.** `opportunity.md` files hold facts about an
opportunity — the posting, comp, research, framing, gaps, decisions and their reasons —
and nothing actionable. If something needs doing, it belongs in this file, grouped by
application, even when the detail behind it lives elsewhere. Check this file at the start
of a session and clear items as they're resolved.

Once a completed (`[x]`) task has been committed, delete it the next time a new task is
picked up. Git history is the record; this file should only ever show live work.
